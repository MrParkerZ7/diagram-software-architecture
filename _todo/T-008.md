## Context

T-001 builds the first diagram in a project library. In doing so it departs from two prompt-master specs, on purpose:

1. **The prompt master's `shared/project-types/LIBRARY.md` section 2a.** It says a builder inside a slot's `_workspace/`
   "writes only inside its own workspace". Here the slot's item is itself generated: a `.drawio`. So the builder in the
   slot's `_workspace/` writes the item into the slot root, the one write outside its workspace.
2. **The prompt master's `shared/workflows/diagram-generate.md`.** Its output path is `<scope>/docs/diagrams/`, which has
   no place in a library: there, every diagram is a new slot.

The owner's standing rule (LIBRARY.md's History, 2026-10-22): "A session's lessons about a kind are written into its
spec in the same turn". This ticket writes both lessons into the prompt master, from what T-001's real slot shows. It is
a separate ticket because it is another repo and another commit (G-001, D10).

**When it runs.** It waits only for T-001's evidence. To keep as close to "the same turn" as a separate ticket allows,
it carries **priority P1** while T-002 to T-007 carry P2. Drives order ready tickets by `when`, then priority, so once
T-001 closes every drive takes this ticket first. That is a priority, not a dependency: T-002 to T-007 do not wait on it.

## Edge cases

- **The commit guard blocks the commit:** the master's `guard-skill-loop.mjs` stops a skill commit whose `Loop:` record is missing or malformed. Fix the record (all five bands, each file with its current hash); never bypass the hook.
- **T-001 deviated from the plan** (another path or another manifest shape): write what T-001 did, and name the deviation in the History row.
- **A core-idea conflict:** stop with `decision:` naming the note and the sentence. Do not pick a side.
- **The master's `main` moved during the work:** pull first, then re-hash the files after any merge, then commit.
- **The push fails** (network, auth): the commit stays local. Report `pushed: no` with the reason; the ticket stays `in-progress`.
